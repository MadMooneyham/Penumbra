Everything Penumbra keeps on the FM-1, as one file on this computer: the eight user journeys, the sound library, the journey playing with its A and B, the loop and its layers, and the settings. The same file puts any of them back, onto this FM-1 or another.

This page talks to the FM-1 over USB-MIDI, in Chrome or Edge (Web MIDI), with Penumbra 1.7 or later on it. Nothing leaves this computer.

Save a backup

What has changed is saved on the FM-1 first, then copied here as penumbra-backup-YYYY-MM-DD.penumbra.

    Restore a backup

    Each part ticked replaces what the FM-1 has; the rest stays as it is. Penumbra then starts again, with what was restored.


      Good to know

      The file is plain text (JSON): each part named, its bytes in base64. A backup from an older Penumbra comes over as that version's journeys did, upgraded; one from a newer Penumbra than the FM-1's is not taken, part by part, and the FM-1 keeps what it had.

      The panel's calibration is the unit's own and is never in a backup. The emulator (Play) saves and restores the same file, so a journey made in the browser can go onto the FM-1, and back.
